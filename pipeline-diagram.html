Pipeline de Build & CI

chongtech-agent-data-pipeline — do código fonte (.claude/) até à instalação por outros utilizadores

Manual — tu corres
Automático — corre sozinho no GitHub
Apoio — testado/usado pelos passos acima

Fonte

.claude/ + plugin-extras/
Onde tu editas agentes, skills, comandos, KBs.

make build / bash build-plugin.sh
enquanto o build corre, usa

scripts/generate-agent-router.py

Regenera o routing dos agentes a partir do frontmatter. Chamado automaticamente pelo build.

tools/spec-linter · spec-judge

Motores Python independentes, copiados para dentro de plugin/tools/.

📦 plugin/

Output gerado — o que é distribuído. Nunca editado à mão (exceto plugin/.claude-plugin/).

make test (opcional, recomendado)

tests/

Testa scripts/generate-agent-router.py e scripts/judge.py — não testa o plugin em si.

git add · commit · push

GitHub

albertochong/chongtech-data-agents-pipeline
(repo remoto)

dispara sozinho, sem intervenção tua

quality-checks.yml

pytest tests/, drift do agent-router, shellcheck, testes do linter/judger

plugin-validate.yml

Valida plugin.json/marketplace.json, corre o build, confirma que não sobrou .claude/ por reescrever

bump-gate.yml

scripts/bump.sh --check — obriga a subir a versão antes de um PR entrar em main

e2e.yml

Instala o plugin de verdade via Claude Code CLI num ambiente limpo e confirma que bateu certo

se tudo passar

Utilizador final

claude plugin marketplace add albertochong/chongtech-data-agents-pipeline
claude plugin install chongtech-agent-data-pipeline
